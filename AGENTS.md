# Instruções para Agentes

## Recomendações Técnicas

- O projeto deve ser uma aplicação .NET (`.net10.0`) (`.slnx`) e um projeto Console App em C#.
- `ImpliciUsings`, namespace no formato file-scoped e nullable reference types habilitados. 
- Mantenha as chaves em declarações de classes, propriedades e métodos.
- Os textos da interface voltadas ao usuário deverão estar em português.
